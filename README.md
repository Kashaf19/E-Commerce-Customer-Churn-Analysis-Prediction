# 🛒 E-Commerce Customer Churn Analysis & Prediction

## 📌 Project Overview

This project focuses on analyzing customer behavior in an e-commerce platform and predicting customer churn using machine learning. The system helps businesses identify customers likely to leave and provides data-driven insights and retention strategies.

---

## 🎯 Objectives

* Analyze customer behavior patterns
* Predict whether a customer is likely to churn
* Visualize churn-related trends
* Assist businesses in making informed retention decisions

---

## 🚀 Features

* Customer churn prediction using a trained ML model
* Bulk dataset upload & analysis
* Single customer churn prediction
* Interactive data visualizations (gender, usage, complaints, coupons, etc.)
* Strategy recommendations based on churn results
* User authentication (Login / Signup)
* Web-based dashboard using Flask

---

## 🧠 Machine Learning Workflow

* Data Cleaning & Preprocessing
* Feature Engineering
* Model Training & Evaluation
* Model Saving (`best_model.pkl`)
* Model Integration into Web Application

---

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Libraries:** NumPy, Pandas, Scikit-learn, Matplotlib, Seaborn
* **Web Framework:** Flask
* **Model Serialization:** Joblib
* **Frontend:** HTML, CSS, Bootstrap

---

## 📊 Dataset Features

Some key features used in this project:

* Tenure
* Preferred Login Device
* City Tier
* Gender
* Hours Spent on App
* Number of Complaints
* Coupon Used
* Order Count
* Days Since Last Order
* Cashback Amount

---

## 📈 Output

* Churn prediction (Yes / No)
* Probability-based insights
* Graphical analysis of customer behavior
* Business-friendly strategy recommendations
